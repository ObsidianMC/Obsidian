# Server sound parity ledger (Minecraft Java 1.21.11)

Scope: **gameplay trigger**, not sound registry entry. `Obsidian/Assets/sounds.json` is generated from vanilla `minecraft:sound_event`; it defines available sound identities, not when they play. A clientbound `LevelEventPacket` or `EntityEventPacket` can cause client audio without a `SoundPacket`. Rows marked **local only** are not vanilla parity claims. For verified rows, vanilla evidence is the local ignored Mojang jar/mappings inspected with `.pi/skills/obsidian-vanilla-parity/scripts/inspect-class.py`; these paths are reproducible, not committed.
